# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/charlespura/Student-Planner-ReactNative.git
```

```
cd Student-Planner-ReactNative
```

Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

---

# ▶ Running the Project

## Web

```bash
npx expo start --web
```

## Android

```bash
npx expo start --android
```

## iOS

```bash
npx expo start --ios
```

## Expo

```bash
npx expo start
```
